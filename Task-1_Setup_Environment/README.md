## Suggested Local Setup

1. Install XAMPP.
2. Start Apache and MySQL.
3. Place `Task-5_Final_Project/blog-app` inside the XAMPP `htdocs` folder.
4. Open `http://localhost/phpmyadmin`.
5. Import `database/schema.sql`.
6. Visit `http://localhost/blog-app/public`.
