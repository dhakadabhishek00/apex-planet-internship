# Task 5 - Final Project and Certification

## Completed Deliverables

- Integrated CRUD blog application.
- Authentication and sessions.
- Search and pagination.
- Prepared statements and validation.
- Role-based permissions.
- Polished responsive interface.
- SQL schema and seed users.

## Run The Project

1. Copy `blog-app` into your local server web root.
2. Create/import the database using `blog-app/database/schema.sql`.
3. Update database credentials in `blog-app/config/database.php` if needed.
4. Open `http://localhost/blog-app/public`.
